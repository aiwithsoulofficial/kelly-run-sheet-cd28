Block 3: Hook up your systems /connect /business-dashboard

Outcome: their real tools plugged into Claude, read-only: payments, CRM, bookings, email and calendar. Their live dashboard opens with their real numbers.

Them

/connect I use [Stripe / Xero / GoHighLevel / Cliniko / Gmail / Google Calendar...]. Start with the one I use every day.
/business-dashboard set me up
  • Keys go in their .env file, never into the chat.
  • Then type my-dashboard in Terminal. It opens at localhost:8765.

Also

  • Staff? /rostering builds next week's roster.

Stripe: a restricted key with Read on balance, charges, payouts and invoices. Xero: a Custom Connection can cost money, so use a CSV export today. GoHighLevel: Settings, Private Integrations, read-only scopes. Windows: the dashboard runs with python dashboard.py serve --open inside .system\business.
